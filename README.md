# 🏋️ Gym Website with Firebase Authentication

A fully functional gym management website built using **HTML**, **CSS**, **JavaScript**, and **Firebase**. This platform includes secure login for **Users**, **Members**, and an **Admin Portal**, offering 
a dynamic and responsive interface for gym operations.
